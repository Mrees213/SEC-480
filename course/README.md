# Course material

Your instructor pushes this directory. Everything outside it is yours.

`module_01/` holds module 1: the setup lab and the technical journal brief.
`module_02/` holds module 2: the pre-class brief, the lab, the handoff packet, the journal brief,
and the deck. `module_03/` holds module 3: the pre-class brief, the lab, the evidence packet you
inherit, the reference document, the journal brief, the survey, Project 1, and the deck.
`showing-your-work.md` explains what process evidence means and applies all term.

Do not edit files in here. If you want to write about one of them, that belongs in your journal
or in your own files. A change made here will be overwritten the next time material is pushed.

Where your own work goes is described in the lab.
