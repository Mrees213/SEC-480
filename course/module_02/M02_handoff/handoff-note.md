You're picking up the host review work. There's an open ticket in `intake.md` and I pulled
the relevant log already, it's `auth.log` in here.

The review itself is pretty intuitive once you've done it a few times. You look at the log,
you work out what happened, you write it up for whoever asked. I've been doing it for about
eight months so it's mostly muscle memory at this point. Honestly the hardest part is just
knowing what's worth flagging and what isn't, and you get a feel for that pretty quickly.

A few things off the top of my head:

- Don't overthink it. Most of these turn out to be nothing.
- If it looks like a brute force, it usually is.
- Timestamps are in local time. I think.
- I usually just skim for the successful login and start from there.
