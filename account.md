# What I Can See

Before the work runs, I can see the instructions I gave it and the settings I chose.

While it runs, if I am not watching it, I cannot see exactly what it is doing step by step.

After it runs, I can see the result and whatever history or records the system provides, but the result by itself does not prove that every step happened correctly.

While the work runs

If I am not watching the task, I cannot directly see what it is doing internally. I do not know exactly which instructions or files it is using at each point unless the system provides logs showing that information.

## After the work runs

Afterward, I can see the task result and its task history. I can compare the result against what I expected, but the finished output alone does not prove that every step ran correctly.
